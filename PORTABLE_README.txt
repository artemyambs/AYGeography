AYGeography — автономная версия для Windows

Установка не требуется:
1. Полностью распакуйте папку AYGeography из архива.
2. Запустите AYGeography.exe внутри этой папки.

Python и подключение к интернету не требуются. Не переносите отдельно только
AYGeography.exe: папка _internal рядом с ним содержит встроенный Python и игровые
ресурсы, необходимые для запуска.

Профили и прогресс хранятся отдельно от приложения:
%LOCALAPPDATA%\AYGeography\save
