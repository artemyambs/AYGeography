# AYGeography

Оффлайн-игра по географии для Windows на Python, Pygame CE и pygame_gui.

## Возможности

- режимы: флаги, столицы, население, страны, акватория и чудеса света;
- 195 стран, 195 флагов и интерактивная карта;
- 44 моря, 6 океанов и 30 рек;
- 75 достопримечательностей, 15 вершин и 195 интересных фактов — минимум по одному для каждой страны;
- уровни сложности, таймер, очки, серии и локальная SQLite-статистика;
- достижения и карта прогресса по странам;
- отдельная очередь точного повторения ошибок с сохранением истории изучения;
- review-раунды до 25 вопросов без удаления остатка очереди;
- локальный журнал с ротацией файлов для диагностики сбоев;
- интерактивный атлас с флагами, справочной информацией и тремя фактами по клику на страну;
- несколько изолированных локальных профилей с импортом и экспортом;
- оконный и полноэкранный режимы.

## Управление

- `1`–`6` — выбрать ответ;
- `Enter` или `Пробел` — перейти дальше после ответа;
- ЛКМ с перетаскиванием или стрелки — перемещать карту;
- колесо мыши, `+` и `−` — менять масштаб;
- `R` — сбросить камеру.
- на паузе: `Esc` — продолжить, `Enter` — закончить раунд;
- в окне выхода: `Esc` — отменить, `Enter` — выйти.

## Разработка

```powershell
python -m pip install -r requirements.txt
python main.py
python -m unittest discover -s tests
```

## Сборка Windows EXE

Запустите `build_exe.bat`. Скрипт создаст отдельное окружение сборки, сформирует
иконку и автономный архив `dist\AYGeography-portable.zip`. На компьютер игрока
нужно перенести архив целиком, распаковать его и запустить
`AYGeography\AYGeography.exe`. Python, установка зависимостей и интернет на
компьютере игрока не требуются. Формат one-folder выбран для быстрого запуска
без временной распаковки большого single-file EXE. Папку `_internal` удалять
или переносить отдельно от EXE нельзя.

Пользовательская база собранной игры хранится в
`%LOCALAPPDATA%\AYGeography\save`, поэтому обновление EXE не удаляет прогресс.
Журнал ошибок находится в `%LOCALAPPDATA%\AYGeography\save\logs\errors.log`;
старые файлы ротируются автоматически.

## Игровые данные

- `configs/water_area/` — отдельные конфиги морей, океанов и рек;
- `configs/wonders/` — достопримечательности, вершины и факты;
- `configs/app_settings.json` — общие настройки, единая UI-тема (палитра, типографика, размеры компонентов), веса категорий чудес, лимиты и задержки;
- `configs/result_levels.json` — подписи, цвета, трофеи и эффекты для диапазонов точности;
- трофеи результата: светящийся золотой для 100%, золотой для 95–99%, серебряный для 60–94% и бронзовый для 0–59%;
- `configs/config_manifest.json` — версии основных конфигурационных документов;
- `configs/progression.json` — режимы и пороги прогресса;
- `configs/difficulty_levels.json` — сложность вопросов по странам.
